# Financial Engineering and Numerical Methods in Python

Python notebooks and scripts covering numerical methods, option pricing, state-price pricing, portfolio optimization, and mean-variance allocation.

## Structure

```text
notebooks/   Original Jupyter notebooks
scripts/     Python script exports for easier code review
data/        CSV and Excel datasets
```

## Topics

- Market data analysis
- Index return and correlation analysis
- Cubic spline interpolation
- Forward and backward substitution
- LU decomposition with row pivoting
- One-period option pricing
- Complete-market state-price pricing
- S&P 500 option bid/ask midpoint analysis
- Mean-variance portfolio allocation
- Tangency portfolio construction
- Maximum-return portfolio under variance/volatility constraints

## Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Note

GitHub may occasionally fail to render Jupyter notebooks directly. For easier review, each notebook is also provided as a Python script export in the `scripts/` folder.
